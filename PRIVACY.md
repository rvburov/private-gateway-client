# Приватность / Privacy

Private Gateway Client не собирает телеметрию, не отправляет разработчику сведений о вас, ваших серверах и подключениях и
не показывает рекламу. Ниже — полный список того, куда программа обращается сама, когда и зачем. Список сверен с кодом
(адреса — в `desktop/src` и `android/core`); новый адрес в коде — строка здесь в том же изменении.

## Куда программа обращается

| Куда | Когда | Зачем | Путь |
| --- | --- | --- | --- |
| Ваши серверы | подключение, замер задержки | туннель и прокси | напрямую — это и есть подключение |
| Адреса ваших подписок | обновление подписки (по кнопке или по расписанию, которое вы задали) | список серверов | по умолчанию — только через VPN («Обновлять только через VPN») |
| `cp.cloudflare.com/generate_204` | замер задержки, проверка связи с сервером, пока «Защищено» | отвечает ли сервер | через сервер |
| `1.1.1.1/cdn-cgi/trace` и `[2606:4700:4700::1111]/cdn-cgi/trace` | после подключения, если включено «Проверять утечки после подключения» (включено по умолчанию), и по кнопкам «Проверки» | внешний IP: какой адрес видят сайты; открывает ли сервер IPv6 | через сервер; один раз на сеть — напрямую, до подключения, чтобы знать реальный IP для сравнения |
| `stun.cloudflare.com:3478` | там же, что и выше | какой адрес видит WebRTC браузера | напрямую — так, как его видит браузер |
| `1.1.1.1:53` | там же | уходит ли DNS мимо туннеля (ответа быть не должно) | мимо туннеля — это проверка утечки |
| `https://1.1.1.1/dns-query` | смена сервера, пока туннель поднят | найти адрес сервера по имени (DNS ОС в это время — сам туннель) | через сервер |
| `stat.ripe.net` | только по кнопке «Кто провайдер» | провайдер и регион внешнего адреса | как у вас сейчас |
| `api.github.com/repos/rvburov/private-gateway-client/releases` и загрузки выпусков | после запуска и раз в 12 часов, если включено «Проверять сами» (по умолчанию), и по кнопке «Проверить» | обновления: список выпусков, подписанный манифест, файл установки | как у вас сейчас |
| DNS из настроек («Cloudflare DoH» — `1.1.1.1`, «Quad9 DoH» — `9.9.9.9`, или ваш) | все время работы туннеля | имена сайтов | через сервер |
| `www.msftconnecttest.com`, `captive.apple.com`, `nmcheck.gnome.org` | только на паузе для входа в Wi-Fi («Открыть на 5 минут») | страница входа гостиничной или публичной сети — ее открывает ваш браузер | напрямую, на время паузы |

Android — то же для своих функций: задержка (`cp.cloudflare.com`), внешний IP и «Кто провайдер» на «Проверке» — только
по кнопкам, обновления — через магазин или установщик, не программой.

## Что хранится и где

- Ключи серверов и адреса подписок — только в хранилище ОС (Windows — DPAPI, macOS — Связка ключей, Linux — Secret
  Service, Android — Keystore); в базе программы — запечатанными.
- Журналы — только на этом компьютере (телефоне), без ключей, UUID, ссылок и адресов подписок; адреса в подробном журнале
  ядра скрыты.
- Отчет проверки («Проверка» → «Экспорт отчета») обезличен: публичные адреса — метками, без ключей, UUID, ссылок, адресов
  подписок и сайтов, реального IP и названия сети. Отправляете его вы сами, программа никуда его не шлет.
- Номер установки для поэтапных обновлений — случайное число 0–99 на этом компьютере; по нему вас не отличить от сотой
  части других, и программа его никуда не отправляет — сравнивает с долей раскатки в манифесте выпуска.
- Резервная копия программы — файл, который вы сохранили сами; на Android резервная копия ОС и перенос на другое
  устройство выключены (без ключа этого телефона копия бесполезна).

## Summary in English

No telemetry, no analytics, no ads. The app contacts only your servers and subscription URLs (subscriptions through the
VPN by default), plus the check endpoints listed above: Cloudflare (`cp.cloudflare.com`, `1.1.1.1`, `stun.cloudflare.com`)
for latency, external IP, WebRTC and DNS-leak checks, RIPEstat only when you press "Who is the provider", GitHub for update
checks (can be turned off in About) and captive-portal pages only when you ask to log in to a Wi-Fi network. Keys and
subscription URLs stay in the OS secure storage; logs and the anonymized check report stay on your device unless you send
them yourself.
