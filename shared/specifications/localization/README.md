# Тексты интерфейса RU / EN

Общие ключи для всех приложений: десктоп читает эти файлы как есть (встроены в сборку), для
Android они превращаются в `strings.xml` (build-logic), для iOS — в свойства `PgTexts` (плагин
`SharedResources` пакета `ios/Core`); и то и другое — при сборке.

- `ru.json`, `en.json` — плоский словарь «ключ → текст». Ключи одинаковые в обоих файлах (тест
  `LocalizationTests` проверяет).
- Подстановки — `{0}`, `{1}` в порядке аргументов.
- В русских текстах нет буквы «е с точками» (AGENTS.md).
- Ключ — по месту на экране: `status.connected.title`, `check.dns.ok`, `server.refresh`.
