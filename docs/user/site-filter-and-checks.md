# Блок сайтов и проверка серверов

Описанные здесь дополнения находятся в исходниках после выпуска 0.3.1. Наличие функции в `master`
не означает, что опубликованный установщик 0.3.1 уже содержит ее. Нужна сборка из новых исходников
с соответствующей службой на компьютере.

## Что означает число в списке серверов

Это время проверочного запроса через профиль, а не скорость загрузки и не гарантия доступности каждого сайта.
Рядом с результатом доступны время и путь проверки. Смена сети, профиля и настроек делает прежнее число
неактуальным. Статус «устарел» требует нового замера; он не означает неисправность сервера.

На компьютере пробы альтернативных серверов при включенном VPN могут идти через текущий VPN.
На Android контролируемые пробы выполняются напрямую через каждый кандидат; на iOS — через текущую
системную сеть. Поэтому числа из разных режимов и клиентов могут заметно отличаться.

Результаты появляются по готовности. «Тайм-аут» означает, что контрольный запрос не завершился в срок;
«TLS» относится к защищенному запросу, а не доказывает неверный ключ REALITY. «Не проверен» объясняет
ограничение безопасного пути проверки. В частности, некоторые UDP-протоколы нельзя проверить через
текущий настольный VPN, не меняя защиту. Выбранный сервер от такого замера сам не меняется.

При неудачном реальном подключении прежний успешный пинг не остается актуальным подтверждением связи.
В карточке компьютера последний успешный замер хранится отдельно от результата текущей попытки.

## Включить блок сайтов без удаленного VPN

1. Откройте «Настройки» → «Маршрутизация» и добавьте нужные правила блокировки.
2. В разделе «Блок сайтов без VPN-сервера» нажмите «Включить фильтр».
3. На телефоне подтвердите системное разрешение на туннель, если оно появится.
4. Убедитесь, что главная показывает «Блок сайтов работает» и «IP виден».

Фильтр применяет правила на устройстве и выпускает разрешенный трафик напрямую. Это не шифрованный
удаленный VPN: провайдер и сайты могут видеть обычные сведения о подключении. Значок VPN в системе
может оставаться, поскольку фильтр использует локальный сетевой адаптер. На телефоне он занимает
системный слот VPN, как и обычное VPN-подключение.

Фильтр включается только явным действием. Новый вход в аккаунт его не запускает.
Для остановки используйте «Выключить фильтр» или кнопку-щит; если задан PIN, приложение запросит его.
Выход из аккаунта останавливает сетевые функции приложения, сохраняя правила и PIN для следующего входа.
На iOS новый вход ждет подтверждения остановки прежнего туннеля и выключения подключения по требованию.
Если система не подтвердила остановку, приложение показывает сообщение и кнопку «Повторить восстановление сети»;
повтор не требует пароля и сам не выполняет вход. До явного нового включения прежняя защита не запускается автоматически,
в том числе после перезапуска приложения.
Системными ограничениями Android «Постоянная VPN» и «Блокировать подключения без VPN» управляет сама ОС;
их пользователь меняет в системных настройках, приложение не обещает снять их автоматически.

На macOS локальный фильтр доверяет сетевым процессам root; обычный трафик пользователя направляется
через фильтр. Это не защита от администратора, способного изменить настройки ОС.
Приложения со своим зашифрованным DNS, неизвестным именем назначения или ECH могут ограничивать
распознавание доменных правил. Неизвестное имя не подменяется догадкой по общему IP.

«Обновлять подписки только через VPN» не разрешает обновление через прямой локальный фильтр.
Для такой загрузки подключите удаленный VPN. Явный первоначальный импорт без требования VPN
сохраняет прежнюю возможность загрузки напрямую.

## Не пустили сегодня

В «Маршрутизации» показываются фактически наблюдавшиеся блокировки: назначение, число попыток
и время последнего события. Попытки — это соединения, а не число открытых страниц.
История ограничена 250 записями в памяти за текущий день и время наблюдения; после остановки,
выхода и смены даты прежние данные не считаются полной историей посещений.

Когда ядро определило имя по TLS/HTTP или FakeDNS, доступно «Разрешить»: создается точное правило
для этого домена. Ослабление существующего блока требует PIN, включая добавление нового разрешения
поверх общего запрета. При неизвестном домене разрешение общего IP одной кнопкой недоступно:
один адрес может обслуживать множество разных сайтов.

История остается на устройстве, не включается в отчет поддержки и резервную копию. В обычный журнал
не записываются полные сообщения ядра о посещенных сайтах. Отсутствие записей не доказывает отсутствие
блокировок до начала наблюдения.

История учитывает подтвержденное ядром применение правила блокировки после определения имени сайта;
предварительное имя назначения само по себе не считается заблокированным посещением. Служебные сведения
для этой истории не включаются в обычный журнал, даже при подробном уровне записи.

## Лаборатория на телефоне

Откройте «Проверка» → «Лаборатория». Доступны путь до сайта с этапами DNS/TCP/TLS, сведения об устройстве
сети, события, разбор последнего отказа и сравнение сохраненных состояний. Снимки для сравнения
сохраняются явной кнопкой: приложение само не отключает защиту ради измерения.

Неизмеренные промежуточные узлы, маршруты провайдера и браузерные проверки не выдаются за пройденные.
Число этапов с ответом помогает разбору, но не устанавливает единственную причину отказа.

## Копия без ключей

Ключи и чувствительные заголовки XHTTP в такую копию не входят. При восстановлении приложение
использует локальные ключи только при однозначном совпадении параметров. Если у нескольких профилей
один адрес, но разные учетные данные, приложение не выбирает первый попавшийся ключ: спорные записи
пропускаются с количеством в результате восстановления. Их можно снова получить из своей подписки.
