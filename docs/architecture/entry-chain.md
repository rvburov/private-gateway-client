# Входной SOCKS5 перед своим VPS

Сайт Private Gateway Web выдает отдельный JSON-пакет `version: 1` для устройства. Он содержит `device_id`,
`node_id`, `subscription_url`, `entry_proxy` и профили VPS. Обычная VLESS-ссылка и обычная подписка содержат
только VPS; их импорт не создает цепочку в стороннем клиенте.

Пакет импортируется на странице «Импорт» десктопного приложения. Входной SOCKS5 применяется к TCP/Vision
и прежнему XHTTP/REALITY по TCP. Это два независимых профиля: выбор между ними остается ручным.
Если пакет содержит XHTTP с TLS/H3, предпросмотр отмечает его как неподдержанный; остальные TCP-профили
можно сохранить. Одного такого H3-профиля для импорта недостаточно. Признак `supports_udp` у прокси сам по
себе не подтверждает работающий UDP ASSOCIATE и relay до VPS.

В базе сохраняются привязка к устройству и адрес с портом SOCKS5. Пароль прокси и полный URL подписки
с токеном находятся в защищенном хранилище ОС. При подключении окно передает профиль и его входной SOCKS5
службе по защищенному IPC. Служба разрешает вне туннеля физический адрес и порт входного SOCKS5, а Xray
соединяется с VPS через него. Замеры выбранного профиля также используют его входной прокси. Старая служба,
не объявившая поддержку цепочки, не получает запрос подключения. Пропавшие секреты или привязка группы
к цепочке вызывают отказ вместо прямого выхода к VPS.

`/sub/entry/…` загружается через сохраненный SOCKS5 с явно заданным прокси HTTP-клиента и без прямого
повтора. После изменения входного прокси на сайте обычное обновление этой подписки заменяет его адрес,
учетные данные и профили одной транзакцией. Новый адрес с токеном при перевыпуске сохраняется при повторном
импорте пакета. Для первого импорта нужен доступ к сайту через другой работающий канал: этот новый SOCKS5
еще не известен приложению.
Обычная резервная копия профилей не содержит учетные данные входного SOCKS5: после ее восстановления
пакет цепочки нужно импортировать повторно. До этого такие профили не подключаются напрямую.
Проверка на физической Windows/macOS машине и выпуск новых окна со службой отмечены отдельно в
[roadmap](../../README.md).
