# Интерфейс десктопа

Как устроен `desktop/src/Client.UI` (Avalonia 12) и откуда в нем берутся цвета, тексты и данные.

## Тема из токенов

```
shared/specifications/design-tokens.json ──dotnet run scripts/gen-tokens.cs──▶ Client.UI/Themes/Tokens.axaml
```

- `Tokens.axaml` генерируется, руками не правится. В шапке — SHA-256 файла токенов; тест
  `ThemeAndMarkupTests` падает, если токены поменяли, а тему не пересобрали.
- Имена ресурсов: `PgColor.*` / `PgBrush.*` (цвета), `PgFontSize.*`, `PgFontWeight.*`,
  `PgLetterSpacing.*`, `PgSpace.*` / `PgPad.*`, `PgRadius.*`, `PgShadow.*`, `PgLayout.*`,
  `PgFont.Ui` / `PgFont.Mono`.
- `Themes/Styles.axaml` — стили блоков (карточка, текст, кнопки, пункт островка, кнопка-щит) только
  на этих ресурсах. Тест запрещает шестнадцатеричные цвета в любой разметке, кроме `Tokens.axaml`.
- `Themes/Icons.axaml` — контуры иконок 24×24 из макета; элемент `Controls/Icon` рисует их линией
  цвета текста вокруг (как шрифтовые иконки).
- Шрифты: Inter — пакет `Avalonia.Fonts.Inter`; JetBrains Mono — `Assets/Fonts` (OFL, лицензия рядом).

## Тексты RU/EN

- Словари — `shared/specifications/localization/{ru,en}.json`, общие для всех приложений;
  встроены в сборку и читаются `Localization/Loc`.
- В разметке — `{l:L ключ}`, рубрики заглавными — `{l:L ключ, Upper=True}`. Модели представлений
  берут тексты из `Loc.Instance[...]` и пересчитывают их по событию `LanguageChanged`.
- Язык меняется на ходу: разметка привязана к `Loc.Revision`, который растет при смене языка.
- Тесты `LocalizationTests`: ключи совпадают в обоих языках, нет пустых текстов и буквы «е с
  точками», все ключи из разметки и кода есть в словаре, у каждого состояния есть свои подписи.

## Окно и страницы

- `Views/MainWindow` — каркас: фон с цветными пятнами (мягкие радиальные градиенты вместо размытия),
  слой стекла `Glass.Fill`, текущая страница, всплывающая подсказка и `Controls/IslandNav`.
- `IslandNav` — островок навигации; контур считается по ширине окна (`IslandGeometry`), тень — из
  токена `shadow.island`, кнопка-щит и подпись под ней — из `ProtectionViewModel`.
- Страницы — модели представлений (`ShellViewModel.Navigate`), разметка подбирается шаблонами в
  `App.axaml`. Главная — `MainPage` (доска 1), «Серверы» — `ServersPage` (доска 2), «Настройки» —
  `SettingsPage` (доска 4), «Проверка» — `CheckPage` (доска 7), «Добавить профиль» — `ImportPage`
  (доска 3, подробно — [import.md](import.md)), «Профили и подписки» — `SubscriptionsPage` (доска 12),
  «Защита и утечки» — `ProtectionPage` (доска 5), «Подключение и ядро» — `CorePage` (доска 6),
  «Маршрутизация» — `RoutingPage` (доска 13), «Резервная копия» — `BackupPage` (доска 14), «О программе»
  — `AboutPage` (доска 15).
- Экран-шаг («Добавить профиль») идет без островка (`ShellViewModel.IsIslandVisible`), со своей
  кнопкой «Назад»; `INavigator.Back` возвращает на страницу, с которой пришли.
- Слой поверх окна вместе с островком — `OverlayViewModel`: затемнение, нижний лист (карточка
  сервера `ServerCardView`, доска 11) и диалог подтверждения (`DialogView`, доска 18). Escape и
  щелчок по затемнению выбирают безопасный вариант; фокус при открытии диалога — на безопасной
  кнопке («Оставить защиту», у удаления — «Отмена»). Смена страницы закрывает лист.

## Серверы

- Отбор и порядок строк — `ServerList` (Application): поиск по названию, городу, коду страны,
  адресу и протоколу; вкладки «Все» (группы по подпискам, серверы без подписки — «Мои серверы»),
  «Избранные» и «Недавние» (10 последних выбранных); фильтр протоколов — только тех, что есть
  среди серверов; сортировка по пингу (недоступные в конце) или по названию по правилам языка.
- Подпись строки — `ServerFacts.Summary`: «VLESS · REALITY», «VLESS · XHTTP», «Trojan · WS».
- Нажатие на строку — `ConnectionController.SwitchServerAsync`: при включенной защите
  переподключение к новому серверу, без защиты — только выбор. Сам сервер не меняется никогда.
- Карточка: звезда «избранное», пинг, сведения (адрес, протокол, транспорт, защита, ядро),
  «Подключиться» (`ConnectToAsync`), переименование, удаление с подтверждением
  (`RemoveServerAsync`: если защита шла через этот сервер — отключение, другой выбирает
  пользователь). «Поделиться» выключено до шага с QR-кодом (решение агента №75).
- Список — свои серверы из базы (`SqliteServerCatalog`); пока своих нет — демо-серверы
  (`UserOrDemoCatalog`).

## Проверка

- `CheckPageViewModel` (доска 7): восемь проверок `DiagnosticCheck` из отчета службы
  (`IGatewayClient.RunChecksAsync`, в контракте — `RunChecks` → `CheckReport`) и журнал службы
  (`IGatewayClient.Journal` и `JournalAdded`, в контракте — `WatchLog`), 50 последних записей.
- Проверки идут сами при открытии экрана и при каждой смене состояния защиты.
- Текст строки: по коду уточнения (`reason`), иначе по состоянию проверки, иначе общий
  (`diag.state.*`) — без «дыр» в словаре для новых сочетаний. Цвета — как у чипов главного экрана.
- Журнал и отчет проходят через `SecretMasker`. «Экспорт отчета» — текст на языке интерфейса через
  окно «Сохранить как» (`IFileSaveService`): без реального IP и имени сети.

## Данные: служба и демо-режим

- Интерфейс узнает о защите только от службы: `IGatewayClient` (Application) — состояние и просьбы
  подключиться, отключиться, проверить. Переходы состояний — `ConnectionStateMachine`.
- Пока службы нет (этап 1), подключена имитация `Infrastructure/Demo/SimulatedGatewayClient` и
  серверы `DemoServerCatalog` (адреса из диапазонов документации). В шапке — значок «демо».
- Кнопка-щит: `ConnectionController.ToggleAsync` — «Выключено» и «Ошибка» включают, остальные
  состояния выключают; нажатие доступно и во время подключения (прерывает его). В «Блокировке»
  сначала диалог «Снять защиту?»: снять — значит открыть сайтам реальный IP.
- Имитация: подключение к серверу без ответа на пинг («нет» в списке) уходит в «Блокировку», а
  выход («Сайты видят ваш IP») — адрес и город выбранного сервера. Проверки в имитации длятся
  1,4 с, строка «Служба» честно говорит «Имитация»; журнал пишет подключения и проверки без имени
  сети.

## Настройки и данные

- `AppSettings` (Core) — раздел «Основные»: режим, блок при обрыве, автозапуск, подключение при
  запуске, сворачивание в трей, уведомления, язык. По умолчанию — решения из DECISIONS.md.
- `SettingsService` (Application) читает настройки один раз и сохраняет каждое изменение сразу.
- `SqliteSettingsStore` (Infrastructure) — таблица `settings (key, value)`; нечитаемое значение —
  значение по умолчанию и предупреждение в журнале.
- `SqliteDatabase` — миграции `Storage/Migrations/NNNN_*.sql` по порядку, версия в `PRAGMA user_version`.
- Папка данных — `AppPaths`: при запуске из репозитория `.localdata/`, иначе папка пользователя ОС;
  `PG_DATA_DIR` перекрывает обе.
- Журнал — Serilog в `<данные>/logs/client-*.log`, по дню, 7 дней, до 10 МБ; каждая строка целиком
  (с исключением) проходит через `SecretMasker` (`MaskingTextFormatter`).

## Профили и подписки

- `SubscriptionsPageViewModel` (доска 12) — подстраница настроек: островок виден, «Назад» ведет в
  «Настройки», «+» и пунктирная кнопка — на «Добавить профиль», а оттуда «Назад» — сюда же.
- Сверху — автообновление (кнопка и всплывающий список: выключено, 6, 12, 24 ч), «Обновлять только
  через VPN» со строкой, почему сейчас не обновляется, и «Сообщать об изменении выбранного
  сервера». Все три сохраняются в `AppSettings` сразу.
- Карточки — из `IServerStore`, только свои серверы: название, адрес без токена, сколько серверов
  и когда обновлялась («обновлено в 18:10», «вчера», «последняя попытка 2 ч назад» — `TimeText` по
  часам программы), метка «Работает» / «Ошибка» / «Вручную», причина ошибки (`FailureText`).
  «Мои серверы» — серверы без группы: без «Обновить» и «Изменить».
- «Обновить» — `SubscriptionUpdater`; итог — уведомлением. «Изменить» — лист
  `SubscriptionEditViewModel` (название и новый адрес). Удаление — диалог (доска 18); если защита
  шла через сервер группы — сначала отключение (`ConnectionController.ReleaseAsync`).
- Выбранный сервер пропал или изменился после обновления — уведомление в окне на 6 секунд (держит
  `ShellViewModel`), в карточке сервера — «Пропал из подписки — остается, пока выбран».
- Обновление по расписанию запускается при старте окна (`SubscriptionUpdater.Start`).

## Пауза для входа в Wi-Fi

- `ConnectionController.PauseForCaptivePortalAsync` просит службу открыть трафик мимо туннеля на
  5 минут (`IGatewayClient.PauseForCaptivePortalAsync`); защита выключена — паузы нет. Конец
  паузы держит служба, раньше — `ResumeAsync`.
- В состоянии — `ConnectionStatus.CaptivePauseUntil` (`IsPaused`): цвет «частично» (желтый),
  «Защита на паузе», полоса с обратным отсчетом и «Вернуть защиту» в карточке состояния, чипы
  «напрямую / у провайдера / открыт / на паузе», в карточке IP — реальный адрес «виден сайтам».
- Кнопка-щит во время паузы — «Вернуть защиту»: нажатие возвращает защиту, а не выключает VPN.

## Защита и утечки

- `ProtectionPageViewModel` (доска 5): блок при обрыве (общий с «Основными»), защита при загрузке,
  строгий режим, «Вход в Wi-Fi», DNS в туннеле (список и лист «Свой адрес DNS»), блок DNS
  провайдера, FakeDNS, проверка утечек после подключения, IPv6 и приоритет адресов, локальная сеть
  и обнаружение устройств. Все — в `AppSettings.Protection`, сохраняется сразу; службе уходит
  через `ContractMapping.ToContract(AppSettings)` (сообщение `ProtectionSettings` контракта IPC).
- Вопросы — `SafetyDialogs`: выключить блок при обрыве (и на экране «Настройки»), включить строгий
  режим, открыть интернет для входа в Wi-Fi. Безопасный вариант — основная кнопка, Escape и
  щелчок мимо.
- Строгий режим недоступен без блока при обрыве, обнаружение устройств — без локальной сети; в
  режиме «Только прокси» блок при обрыве недоступен, и экран говорит почему.
- Списки выбора (DNS, приоритет адресов, автообновление подписок) — кнопка `Button.select` и
  всплывающий список из `ChoiceOptionViewModel`.
- Адреса открываются через `IUrlLauncher` (браузер пользователя): сам интерфейс в сеть не ходит.

## Подключение и ядро

- `CorePageViewModel` (доска 6): сведения о ядрах, журнал ядра; TUN — стек, MTU (список и лист
  «Свой MTU», 1280–1500), строгие маршруты, определение домена; соединение — отпечаток TLS, Mux,
  TLS-фрагментация, таймаут, переподключение (только к выбранному серверу); режим прокси — порт и
  доступ из локальной сети (с вопросом).
- Все — в `AppSettings.Connection`, сохраняется сразу; службе уходит в запросе Connect
  (`ContractMapping.ToConnection`, сообщение `ConnectionSettings` контракта IPC).

## Маршрутизация

- `RoutingPageViewModel` (доска 13): режим «Весь трафик» (по умолчанию) или «Раздельный режим»,
  программы мимо VPN, правила для сайтов, «Всегда напрямую». Все — в `AppSettings.Routing`,
  сохраняется сразу (списки — JSON в таблице настроек); службе уходит через
  `ContractMapping.ToRouting` (сообщение `RoutingSettings` контракта IPC).
- Мимо VPN идет только выбранное в раздельном режиме: программы (включенные) и правила «Напрямую».
  В режиме «Весь трафик» список программ скрыт, правила «Напрямую» остаются в списке бледными и
  службе не уходят; «Блокировать» и «Через VPN» действуют всегда. В раздельном режиме над списками —
  предупреждение: мимо VPN виден реальный IP и не действует блок при обрыве.
- Программа выбирается окном ОС (`IFileOpenService.PickProgramAsync`): на Windows — `.exe`, имя —
  описание из файла, на macOS — приложение `.app`, на Linux — любой файл. Повторный выбор той же
  программы не заводит вторую строку, а включает ее. Убрать — значок корзины в строке.
- Правило — лист `SiteRuleEditViewModel`: шаблон (`SitePattern`: домен, `*.домен`,
  `geosite:категория`; адрес `https://…` сокращается до домена) и действие. На один сайт — одно
  правило: новое правило для того же сайта заменяет прежнее. Нажатие на правило — правка и «Удалить».
- «Локальная сеть» показывает, разрешена ли она, и ведет на «Защиту и утечки»: настраивается в одном
  месте.
- Главный экран при включенной защите в режиме VPN показывает полосу «Внимание · программы и сайты
  из списков идут мимо VPN» (`MainPageViewModel.HasBypass`), если в раздельном режиме что-то
  действительно идет мимо туннеля (`RoutingSettings.HasBypassApps`, `HasBypassSites`); нажатие ведет
  в «Маршрутизацию». Во время паузы для входа в Wi-Fi ее заменяет полоса паузы.

## Резервная копия

- `BackupPageViewModel` (доска 14): что сохранить — серверы и подписки (со ссылками на подписки),
  настройки, ключи доступа (только вместе с серверами, с предупреждением); пароль файла — не короче
  8 знаков, с кнопкой «показать». Файл сохраняется окном ОС с расширением `.pgbackup`.
- Формат и шифрование — `Infrastructure/Backup`: `BackupFile` — JSON-обертка (формат, версия,
  параметры ключа, соль, nonce, время создания) и данные AES-256-GCM; ключ — PBKDF2-SHA256, 600 000
  повторов. Обертка входит в проверку подлинности: подменить время или параметры незаметно нельзя.
  Неверный пароль и испорченный файл AES-GCM не различает — так и говорим.
- `BackupService`: настройки — те же пары «ключ → значение», что в базе (`SqliteSettingsStore.Values`
  и `Parse`): при восстановлении негодные значения заменяются значениями по умолчанию. Серверы —
  `IServerStore.Snapshot` и `Restore`: все группы и серверы заменяются содержимым копии за одну
  транзакцию; серверу без ключей достаются ключи такого же сервера здесь, иначе он пропускается и
  попадает в счет «без ключей пропущены»; подписки с адресом обновятся при ближайшей проверке.
- Восстановление: файл выбирается кнопкой или перетаскивается на рамку; не копия — подсказка сразу.
  Лист `RestoreBackupViewModel` — сначала пароль, потом что в копии и «Восстановить»: до этого ничего
  не меняется. Перед восстановлением служба сама сохраняет автокопию — все, включая ключи,
  зашифровано случайным ключом из хранилища ОС (`backup:autocopy`), файл `autocopy.pgbackup` в папке
  данных. «Последняя автокопия · Восстановить» (с вопросом) возвращает состояние до восстановления,
  а текущее само становится новой автокопией. Без хранилища ОС восстановление не начинается.
- После восстановления язык окна берется из восстановленных настроек.

## О программе

- `AboutPageViewModel` (доска 15): «Версия 0.1 · Windows 11 · x64» (`AppInfo.OsVersion`, `Architecture`;
  на Linux — название дистрибутива из /etc/os-release), обновления — честно: появятся с первым
  подписанным выпуском; канал «Стабильный / Бета» сохраняется в `AppSettings.UpdateChannel`.
- Компоненты — без заглушек: служба в демо-режиме, ядра не установлены, TUN-драйвер — по ОС.
- Лицензии открытых компонентов — `AboutPageViewModel.Components`; тест `License_list_covers_every_package_the_app_ships`
  сверяет список с пакетами проектов `desktop/src`: новый пакет без лицензии на экране не пройдет.
  Политика конфиденциальности — текст на листе `AboutSheetViewModel`; «Сообщить о проблеме» — экран
  «Проверка» с обезличенным отчетом.
