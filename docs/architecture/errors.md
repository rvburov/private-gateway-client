# Коды ошибок

Каталог — `Client.Core/ErrorCodes`. Служба присылает код (`ErrorInfo.code`, `Status.error`),
интерфейс показывает свой текст на языке пользователя; в журнале — код и подробности без секретов.
Код выглядит как `PGC-<область>-<номер>`: SVC — служба и ядро, NET — сеть.

| Код | Когда | Что видит пользователь |
| --- | --- | --- |
| `PGC-SVC-001` | служба не запущена или не установлена; служба не ответила на подключение или пропала, пока защита была включена; служба пользователя не запустилась (код ставит само окно) | экран «Служба не запущена» (доска 16): работать в режиме прокси (служба пользователя), позже — установить службу; на главной — «защиты нет, трафик идет напрямую» |
| `PGC-SVC-002` | ядро не запустилось, не открыло вход за время подключения или остановилось само | «Ошибка службы», код в строке под заголовком |
| `PGC-SVC-003` | запрос не разобран: незаданные значения, данные не того протокола, порт вне 1–65535, сервер удален из списка | отказ подключения — «Ошибка» с кодом |
| `PGC-SVC-004` | режиму VPN нужны права администратора: служба запущена без них (служба пользователя) | экран «Нужны права администратора» (доска 16): работать в режиме прокси или отмена |
| `PGC-SVC-005` | ядро не возьмется за сервер: Hysteria2 и TUIC — до второго ядра, нет ключа, транспорт не тот | отказ подключения с объяснением |
| `PGC-SVC-006` | режим VPN на этой ОС еще не готов: нет блока при обрыве (Windows — до WFP, macOS) или сборки sing-box | отказ подключения; уйдет, когда блок будет на всех ОС |
| `PGC-SVC-007` | блок при обрыве не включился: правила брандмауэра не поставить | «Ошибка», ядра не запускаются; защиты нет — «трафик идет напрямую» |
| `PGC-NET-001` | сервер не отвечает | в режиме прокси — «Ошибка», не «Блокировка»: перекрывать нечем |
| `PGC-NET-002` | адрес сервера не найден: имя не разрешилось (или блок при обрыве без туннеля) | отказ подключения, блок снят; следующее подключение найдет адрес |
| `PGC-NET-010` | работает другой VPN или системный прокси | экран «Работает другой VPN» (доска 16) |

Новый код — строка здесь и константа в `ErrorCodes`; номер не переиспользуется.
