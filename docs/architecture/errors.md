# Коды ошибок

Каталог — `Client.Core/ErrorCodes`. Служба присылает код (`ErrorInfo.code`, `Status.error`),
интерфейс показывает свой текст на языке пользователя; в журнале — код и подробности без секретов.
Код выглядит как `PGC-<область>-<номер>`: SVC — служба и ядро, NET — сеть.

| Код | Когда | Что видит пользователь |
| --- | --- | --- |
| `PGC-SVC-001` | служба не запущена или не установлена | экран «Служба не запущена» (доска 16): установить службу или работать в режиме прокси |
| `PGC-SVC-002` | ядро не запустилось, не открыло вход за время подключения или остановилось само | «Ошибка службы», код в строке под заголовком |
| `PGC-SVC-003` | запрос не разобран: незаданные значения, данные не того протокола, порт вне 1–65535 | отказ подключения, состояние не меняется |
| `PGC-SVC-004` | режиму VPN нужны права администратора: служба запущена без них (служба пользователя) | экран «Нужны права администратора» (доска 16) |
| `PGC-SVC-005` | ядро не возьмется за сервер: Hysteria2 и TUIC — до второго ядра, нет ключа, транспорт не тот | отказ подключения с объяснением |
| `PGC-SVC-006` | режим VPN в этой сборке службы еще не готов (TUN и брандмауэр — этап 3) | отказ подключения; временный код, уйдет вместе с TUN |
| `PGC-NET-001` | сервер не отвечает | в режиме прокси — «Ошибка», не «Блокировка»: перекрывать нечем |
| `PGC-NET-010` | работает другой VPN или системный прокси | экран «Работает другой VPN» (доска 16) |

Новый код — строка здесь и константа в `ErrorCodes`; номер не переиспользуется.
