# Разбор безопасности перед первым выпуском

2026-10-27, по [модели угроз](threat-model.md) — поверхности, которые появились после нее: приложение Android, входы ядер
на 127.0.0.1 (TUN, ретранслятор Hysteria2 и TUIC, замер задержки), обновления. Как читалось: путь данных в коде и тесты,
которые его держат; что нашлось — исправлено в том же коммите, что этот документ (решение 454). Следующий разбор — перед
выпуском, который добавит новую поверхность (iOS, новый протокол, новый способ обновления).

## Десктоп: входы ядер на 127.0.0.1

Служба работает от SYSTEM или root, а 127.0.0.1 видит любая программа на машине. Вход без пароля — дверь к серверам
пользователя в обход TUN и его правил.

| Вход | Пароль | Итог |
| --- | --- | --- |
| Прокси (режим прокси, порт из настроек) | нет — это сам прокси для программ пользователя; наружу — только с согласия («Подключение и ядро») | так задумано |
| TUN и обход FakeDNS (режим VPN) | имя и пароль по 128 случайных бит на подключение, порт случайный | в порядке (`VpnTunnelTests`) |
| Проба связи с сервером | то же | в порядке |
| Ретранслятор Hysteria2 и TUIC | то же; ключи сервера знает только он | в порядке (`RelayTests`, решение 452) |
| Замер задержки (`LatencyProbe`) | **не было** — входы без пароля жили, пока идет замер | исправлено: имя и пароль на каждый замер (`SocksAccount`), тест конфига и мутант |

Конфиги и пароли всем ядрам — через stdin, не через файлы и аргументы процесса (их видят другие программы).

## Десктоп: служба, окно, обновления

- Канал IPC — ACL и uid собеседника, окно проверяет, кто на том конце; служба не принимает конфиги, пути и команды —
  только описание сервера (`ServiceIpcTests`, `ServiceGatewayClientTests`, тесты `Architecture`). Без изменений.
- Обновления: манифест подписан ECDSA P-256, версия — выше установленной и равна тегу, файлы сверяются по SHA-256 из
  манифеста, ссылки — только на загрузки выпусков этого репозитория, размер ограничен при загрузке (`GitHubReleaseFeed`),
  откат — только на версию, что стояла на этой машине; доля раскатки 0 % — стоп-кран (решение 451). Без изменений.
- Первая установка: SmartScreen и Gatekeeper предупредят — подписи кода нет (ROADMAP, «Отложено»); целостность загрузки
  держит `SHA256SUMS` того же выпуска. Остаточный риск: сумма лежит там же, где файл, — подмену выпуска на GitHub она не
  поймает; закрывает подпись кода.

## Android

| Что | Как устроено | Итог |
| --- | --- | --- |
| Другие приложения на телефоне | наружу открыты только окно запуска (из intent берется лишь выбор вкладки) и плитка в шторке (ее вызывает только система, `BIND_QUICK_SETTINGS_TILE`; включает VPN только после разблокировки, решение 415); `VpnService` запускает только система (`BIND_VPN_SERVICE`), приемник кнопки уведомления не открыт; локальных входов у ядра нет — TUN по дескриптору карты | в порядке |
| Ключи серверов и адреса подписок | AES-256-GCM ключом Android Keystore, ключ не покидает хранилище; резервная копия и перенос на другое устройство выключены | в порядке |
| Журнал Android | ошибки ядра и сети — через `SecretMasker` | в порядке |
| Человек, взявший телефон: экран блокировки | уведомления о сервере и подписке скрывают текст; **уведомление туннеля показывало название сервера** | исправлено: на экране блокировки — только состояние (`VISIBILITY_PRIVATE` и версия без текста), проверка на эмуляторе (`TunnelOnDeviceTest`) |
| Снимки экрана и «Недавние» | QR и ссылка с ключом («Поделиться») — без снимка в «Недавних» | в порядке |
| Буфер обмена | ссылка с ключом копируется с пометкой «секрет» (Android 13+ не показывает ее в подсказках) | остаточный риск: на Android 12 и раньше пометки нет — буфер видят клавиатура и приложение, которое пользователь открыл; предупреждение «ссылка с ключом» рядом с кнопкой |
| Фоновая работа | подписки в фоне обновляются напрямую, только если пользователь выключил «только через VPN» | в порядке |
| Блок без VPN | системный: включает только пользователь, приложение честно показывает, что сообщил Android | в порядке |
| Hysteria2 и TUIC | libXray их не знает — отказ `PGC-SVC-005`, трафик не идет мимо | в порядке |

## Сборка и цепочка поставки

- Ядра десктопа — закрепленные SHA-256 (`shared/cores`), libXray — из закрепленного коммита со сверкой `go.sum`; SBOM у
  выпусков десктопа и у APK (решение 453); секреты в коммитах ловит gitleaks в CI.
- Остаточный риск: Gradle не сверяет суммы библиотек Android (`verification-metadata.xml` не включен) — подмена пакета в
  репозитории Maven прошла бы в APK. Включить вместе с подписью выпуска Android (ROADMAP, «Отложено»).

## Итог

Найдено и исправлено два места: входы замера задержки без пароля и название сервера на экране блокировки Android. Остаточные
риски — подпись кода и сверка сумм библиотек Android — записаны в разделе «Отложено» ROADMAP; оба закрываются вместе с
подписью выпусков.
