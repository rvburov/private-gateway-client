# Флаги и названия серверов

Флаги десктопа берутся из квадратного варианта 1:1 закрепленного `flag-icons`, а не из эмодзи ОС.
По просьбе пользователя возвращены исходные изображения, размеры и пропорции: рисунок с рамкой занимает 28×28,
PNG — 112×112; неизвестная страна остается квадратной Землей. На встроенном экране MacBook прежний вариант
отображался правильно; смена масштаба при отключении внешнего монитора проверяется отдельно.
Все варианты используют один ресурс на Windows, macOS и Linux. Android и iOS пока показывают буквенный код страны.

Название для показа на всех платформах отделяет эмодзи от соседних букв, цифр и эмодзи обычным пробелом.
Уже существующие пробелы, пунктуация и составные символы сохраняются. Исходное имя подписки, поле переименования,
поиск и экспорт не меняются. Общие примеры — `shared/testdata/server-name-display.json`.

## Проверка на устройстве

1. Открыть список с США, Японией, Нидерландами и неизвестной страной. Флаги имеют прежний квадратный вид,
   рамка совпадает с рисунком. Земля не сплющена. Повторить на обычном и увеличенном масштабе ОС.
2. Проверить имена `⚡🇩🇪Germany-1 DIRECT`, `👩🏽‍💻Server`, `1️⃣Server`. В списке, карточке и на главной между значком
   и словом есть пробел; флаг, оттенок кожи, ZWJ и keycap остаются одним символом.
3. Открыть переименование: исходное имя осталось без добавленных отображением пробелов. Закрыть, обновить список
   серверов и перезапустить приложение: серверы не дублируются, свои названия и выбор сохраняются.
4. При отказе в разрешении хранилища окно остается открытым, прежние карточки сохраняются; после разрешения снова
   нажать «Обновить серверы». Отказ не должен удалять список и не должен менять оформление флагов или названий.

Автоматические проверки: общие примеры в Unit, Android core и iOS Core; UI — геометрия флагов, смена известной/неизвестной
страны и сохранение исходного имени при переименовании. Снимок из headless-проверки не заменяет проверку шрифта и масштаба
на MacBook M4.
