## На M4 после обновления

1. В «О программе» проверить версию клиента. Открыть «Серверы»: флаги квадратные, радиус небольшой,
   белый фон Японии отделен тонкой рамкой. При неизвестной стране — Земля на синем фоне.
2. Импортировать обычную ссылку без эмодзи страны и стороннюю подписку. Для IP результат локальный;
   для доменов после появления службы дать DNS-проверке несколько секунд. Служба не подключена —
   доменные строки могут оставаться с Землей до ее запуска. Ссылки и секреты в отчет не отправлять.
3. Подключиться к выбранному серверу с выключенными другими VPN. Флаг у IP на главной относится к
   измеренному выходу. Если сервер использует внешний прокси, страна выхода может отличаться от
   страны адреса подключения в списке.
4. Скрыть IP глазом: флаг заменяется Землей. Показать — определяется по текущему IP. Отключить VPN:
   в состоянии ожидания Земля, после измерения прямого IP — страна этого адреса.
5. Не проверять блокировку по одному флагу: состояние защиты и Kill Switch подтверждаются прежними
   сетевыми проверками. Эта функция не меняет политики подключения.

При неверном значке нужны версия, снимок строки (секреты скрыты), указание «сервер / измеренный выход»,
ожидаемая страна и основание ожидания. Не присылать ссылку подписки, ключи, UUID, пароли.
Геобаза имеет ограничения: [источник и обновление](../architecture/ip-countries.md).
