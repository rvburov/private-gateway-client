# Проверка установки службы: 2026-11-05

Проверена ветка repo-check на базе origin/master 18f4f99, macOS ARM64, .NET SDK 10.0.107.
Проверки выполнены без установки службы, смены маршрутов, DNS, системного прокси или брандмауэра.

## Изменение

Сборка UI готовит автономную службу и кладет рядом .NET, ASP.NET Core, Xray и sing-box.
Кеш ядер берется из основной папки; если его нет, работают штатные скрипты загрузки с проверкой сумм.
На macOS используется apphost PrivateGatewayService: те же байты с окончанием .Service в автономной
папке завершаются кодом 137, под другим именем запускаются. Управляемая DLL остается прежней.
Выпуски уже публиковались self-contained; smoke-проверка учитывает новое имя macOS.

Установка передает проценты по подтвержденным этапам, а не по таймеру. TUN и правила появляются при
подключении, их установка не изображается завершенной. Окно прекращает ожидание через 2 минуты,
не убивая привилегированный процесс посередине замены. Файловый замок исключает параллельные
установки и проверяется новым окном до повторного запроса прав. Старый установщик без этой
блокировки автоматически не останавливается.

## Результаты

`dotnet build PrivateGateway.slnx -c Release --no-incremental`: 0 ошибок, 0 предупреждений;
штатная подготовка автономной службы с ядрами включена.
`dotnet format PrivateGateway.slnx --verify-no-changes --no-restore`: успешно.

| Проверка Release | Всего | Успешно | Ошибки | Пропуски |
| --- | ---: | ---: | ---: | ---: |
| Unit | 1045 | 1044 | 0 | 1 |
| Architecture | 19 | 19 | 0 | 0 |
| UI | 419 | 419 | 0 | 0 |
| Network, только ServiceSetupTests | 24 | 22 | 0 | 2 |

Unit пропускает реестр Windows на macOS. ServiceSetupTests пропускает настоящую установку
службы Windows и root-установку launchd. Остальные Network-тесты в этот прогон не входят.
Полный UI-прогон занял 1 минуту 34 секунды; снимок welcome-service-progress проверен визуально.

`env -u DOTNET_ROOT -u DOTNET_ROOT_ARM64 -u DOTNET_ROOT_X64 ./artifacts/dev-service/release/PrivateGatewayService --version`
возвращает `Private Gateway Service 0.1.0 (IPC v1)` без зарегистрированной системной .NET.
Наличие libhostfxr.dylib, libcoreclr.dylib, ASP.NET Core и обоих ядер проверено в комплекте.

Семь независимых контрольных ошибок отвергнуты тестами: потеря тайм-аута, принятие прогресса чужой
попытки, выбор зависимой службы вместо автономной, потеря прогресса в UI, неверный этап копирования,
обход замка новым окном и потеря исключительности замка. Исходный код восстановлен, Release
пересобран без инкрементальности, итоговые тесты зеленые. Gitleaks 8.30.1 не нашел секретов.

## Осталось проверить на настоящей машине

Сначала завершить старый зависший установщик, затем отдельно проверить установку от администратора,
ответ launchd и работу VPN. Эти действия не выполнялись. Новая сборка не подтверждает исправность
TUN, DNS или брандмауэра на машине пользователя. Новые установщики держат замок; старые версии
такого протокола не имеют. Пакет DMG и Windows/Linux здесь не проверены; их проверяет штатный CI.
