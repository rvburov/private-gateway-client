# Проверка iOS на вашем iPhone

Что проверяется только на настоящем iPhone: туннель с ядром Xray (на симуляторе расширение Packet Tunnel не запускается),
блок при обрыве (`includeAllNetworks`), переподключение и уведомления из расширения, «Постоянная защита» после
перезагрузки, сон, настоящая смена Wi-Fi и мобильной сети, камера, Связка ключей. Пункты ROADMAP этапа 10 «Подпись,
provisioning, TestFlight» и «реальные iPhone» закрываются по итогам этой проверки.

CI уже проверяет без вас на симуляторе iPhone: сборку приложения и расширения с настоящим libXray, все экраны на обоих
языках, QR туда и обратно по всем эталонным ссылкам, замеры DNS и TCP на 127.0.0.1, замер задержки настоящим libXray в
процессе приложения; общий пакет — разбор ссылок и подписок, конфиг ядра, план туннеля, переподключение и уведомления на
виртуальном времени, сертификаты (на Linux и macOS).

Адреса серверов, ключи и ссылки в ответ не присылайте: в итогах достаточно «да» или «нет» и, если что-то не так, —
текст на экране и время. Журнал туннеля на «Проверке» адресов и ключей не содержит — его можно прислать целиком.

## Подготовка (один раз)

Расширению туннеля нужна возможность Network Extension, а она есть только у платного аккаунта Apple Developer
(бесплатный Apple ID ее не дает). Пока аккаунта нет, проверка ждет его (решение 2026-10-25).

1. Mac с Xcode 26 и go (`brew install go`), iPhone с iOS 16 или новее, кабель.
2. В Терминале:

   ```bash
   git clone https://github.com/rvburov/private-gateway-client.git
   cd private-gateway-client
   scripts/ios-test.sh
   ```

   Скрипт соберет ядро, проект и прогонит тесты на симуляторе. Дождитесь строки «Тесты iOS: всего …, упало 0».
3. Откройте `ios/PrivateGateway.xcodeproj` в Xcode. Слева — проект **PrivateGateway** → цель **PrivateGateway** → вкладка
   **Signing & Capabilities** → **Team** — ваша команда. Если Xcode пишет, что идентификатор занят, поменяйте в
   `ios/project.yml` префикс `com.privategateway.client` (у приложения, расширения и группы `group.…`) на свой и снова
   выполните `scripts/ios-project.sh`.
4. То же для цели **PacketTunnel**: **Signing & Capabilities** → **Team**.
5. Подключите iPhone, вверху Xcode выберите его вместо симулятора → **Product** → **Run**. На iPhone: **Настройки** →
   **Основные** → **VPN и управление устройством** → ваш профиль разработчика → **Доверять**. На iOS 16 и новее — еще
   **Настройки** → **Конфиденциальность и безопасность** → **Режим разработчика** → включить и перезагрузить.
6. **Private Gateway** → **Серверы** → **+** → **Из буфера обмена** (ссылка сервера заранее скопирована) → **Вставить** →
   **Добавить 1 сервер**.

## 1. Защита и трафик

1. **Главная** → кнопка щита → окно iOS «Private Gateway хочет добавить конфигурации VPN» → **Разрешить**, код iPhone;
   затем запрос на уведомления → **Разрешить**.
2. Ждите «Защищено». В строке состояния — значок VPN.
3. В Safari откройте любой сайт проверки IP: адрес должен совпасть с адресом сервера. **Проверка** → **Внешний IP** →
   **Измерить** — тот же адрес и «через сервер».
4. Кнопка щита еще раз — «Выключено», значок VPN пропал, сайт показывает адрес провайдера.

Итог: «IP совпал с сервером — да/нет», «после отключения — адрес провайдера — да/нет».

## 2. Блок при обрыве

1. **Настройки** → **Защита и утечки** → **Kill Switch (fail-closed)** — включен (так по умолчанию).
2. Подключитесь. На **Главной** выберите в **Сменить** другой сервер — защита не выключается, сайт проверки IP
   показывает адрес нового сервера.
3. Включите **Авиарежим** на 10 секунд и выключите. Пока туннель поднимается заново, сайты не открываются (а не
   открываются напрямую); потом снова открываются через сервер.

Итог по каждому шагу — «да/нет».

## 3. Переподключение и уведомления

1. Подключитесь, затем выключите Wi-Fi (останется мобильная сеть) и через минуту включите обратно.
2. Сайты открываются через сервер без нажатий. **Проверка** → **Журнал туннеля** → **Обновить**: видны записи о
   соединении; если связь пропадала — «connection lost» и «connection restored».
3. Если есть возможность сделать сервер недоступным (выключить его на пару минут): уведомление «Соединение потеряно» или
   «Сервер не отвечает»; с включенным блоком при обрыве на **Главной** — «Ошибка» с кодом, сайты не открываются, пока не
   нажмете **Повторить** или не выберете другой сервер.

Итог: «после смены сети туннель работал — да/нет», текст уведомлений, если были.

## 4. «Постоянная защита»

1. **Настройки** → **Защита и утечки** → **Постоянная защита** — включить. Подключитесь.
2. Перезагрузите iPhone и разблокируйте его, приложение не открывайте: через несколько секунд в строке состояния появляется
   значок VPN, сайты открываются через сервер.
3. Откройте приложение, кнопка щита — «Выключено», и защита не включается сама снова.
4. Верните как было: **Постоянная защита** — выключить.

Итог по каждому шагу — «да/нет».

## 5. Сон

1. Подключитесь, включите **Режим энергосбережения** (Пункт управления).
2. Заблокируйте iPhone и оставьте минимум на 30 минут, лучше на ночь.
3. Разблокируйте: значок VPN на месте, сайты открываются без переподключения; в **Журнале туннеля** нет «gave up».

Итог: «после сна туннель работал — да/нет».

## 6. Добавление, QR, подписки, задержка

1. **Серверы** → **+** → **QR-код** → **Сканировать камерой**: наведите на QR со ссылкой сервера (например, из **Поделиться** карточки
   сервера на другом телефоне) — сервер добавляется.
2. **+** → **Ввести ссылку** → адрес подписки → **Проверить** → **Добавить** — серверы подписки появились группой.
3. **Настройки** → **Профили и подписки** → у подписки **Обновить**: сообщение «… обновлена: новых N, удалено M».
4. Без защиты: **Серверы** → круглая стрелка вверху (**Обновить серверы**) — у серверов появилась задержка в мс,
   сообщение «Задержка проверена». Под защитой — «Задержка меряется, пока VPN выключен».

Итог по каждому шагу — «да/нет».

## 7. «Проверка»

1. **Сеть iPhone**: Wi-Fi (или сотовая) и под защитой — VPN (utun); «выход в интернет есть».
2. **Замер** → **TLS**, узел `example.com`, порт `443` → **Проверить**: «TLS 1.3 · сертификат в порядке» или «TLS 1.2 …»,
   ниже — кто выдал сертификат и до какого числа.
3. **DNS**, узел `example.com` → **Проверить**: адреса и время поиска.

Итог по каждому шагу — «да/нет».
