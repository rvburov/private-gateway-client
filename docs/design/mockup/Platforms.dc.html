Одно окно — три системы

Интерфейс общий (C# · Avalonia): одинаковые экраны, цвета, шрифты и компоненты. Отличается только рамка окна, место значка (трей или строка меню), сочетания клавиш и способ установки службы.

Windows 10 / 11
Private Gateway
  • Фон окна — эффект Mica (Windows 11), на Windows 10 — сплошной светлый
  • Значок в трее у часов, сочетания с Ctrl
  • Кнопки окна справа
macOS
Private Gateway
  • Фон — системный эффект прозрачности (vibrancy)
  • Значок в строке меню сверху, сочетания с ⌘
  • Кнопки окна слева, заголовок по центру
Linux (GNOME, KDE и др.)
Private Gateway
  • Размытие не везде есть — тогда сплошной светлый фон
  • Значок в панели (AppIndicator), сочетания с Ctrl
  • Рамка окна — от оболочки (GNOME, KDE)
