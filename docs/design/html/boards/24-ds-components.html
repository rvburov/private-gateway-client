Компоненты дизайн-системы — блоки assets/app.css, те же, что стили Themes/Styles.axaml программы. Каждый в состояниях: обычное, наведение, нажатие, фокус (Tab), выключено — наведение и прочие состояния подписаны над столбцами и нарисованы принудительно, а живой образец рядом реагирует на мышь. Все нажимается: переключатели, флажки, сегменты (переход на «Только прокси» — через диалог), выпадающий список, плитки проверок с пояснением, вкладки, лист, диалоги, меню, подсказка, щит островка и выбор состояния. Не экран программы, поэтому без рамки устройства.

Private Gateway · дизайн-система v1.1

Компоненты

Каждый блок собран только из токенов «Основ» (доска 23) — без цветов и размеров на глаз. Справа над образцом — ключ стиля Avalonia, слева в строке — класс макета. Правила программы после v1.0: наведение — синий текст и значки без серой заливки, выбранный пункт — заливкой оттенком акцента, синим полужирным, недоступное — серый текст без фона, стрелки строк-ссылок — по правому краю, скрытое — звездочками.

Перейти в режим прокси?

Через сервер пойдут только браузеры и программы, которые берут системный прокси. Остальной трафик — терминал, Git, фоновые службы — пойдет напрямую, блок при обрыве работать не будет. Если защита включена, подключение сразу перезапустится в режиме прокси.

Выключить блок при обрыве?

Если VPN оборвется, трафик пойдет напрямую через провайдера — сайты увидят ваш реальный IP.

  • Опасное включается и выключается только через диалог: «Только прокси», выключение блока при обрыве
  • Недоступная строка (.setting.disabled) — серые заголовок и подпись, переключатель 0,45
  • Поиск: значок, поле без рамки, фильтр справа; ссылки и ключи — моноширинным

Правила для новых блоков

  1. Только токены «Основ»: цвет, шрифт, скругление, тень — var(--pg-…) здесь и ресурс темы в программе
  2. Зона нажатия — не меньше 44 × 44
  3. Контраст текста — не ниже 4,5 : 1
  4. Состояния: обычное, наведение, нажатие, фокус (Tab), выключено
  5. Наведение — синий текст и значки, без серой заливки
  6. Выбранный пункт — синим полужирным, без заливки
  7. Недоступное — серый текст, без фона
  8. Стрелки строк-ссылок — по правому краю, строки разделены полосами
  9. Скрытое — звездочками «*»
  10. Статус — значком и текстом, не только цветом
  11. Тексты RU и EN — закладывать +30 % длины
  12. Экран один на всех устройствах: меняются только рамка ОС, шрифт и поля
  13. Новый блок — сначала в app.css и Styles.axaml, потом на экранах
