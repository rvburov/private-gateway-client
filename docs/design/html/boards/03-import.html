«Добавить профиль» (ImportPage программы) — шаг без островка, «Назад» возвращает на главную. Нажатие на источник выбирает его (белая карточка с синей рамкой) и показывает предпросмотр: сколько серверов найдено, новых, дублей и ошибок с номерами строк. «Ввести ссылку» раскрывает поле для ссылок или адреса списка серверов, предпросмотр — после «Проверить». Список серверов, которая уже добавлена, обновится в своей группе — поля названия тогда нет. «Добавить N серверов» сохраняет и ведет на «Серверы».
