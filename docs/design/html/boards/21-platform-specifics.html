Где живет значок программы и как ставится служба на каждой ОС. Меню значка — системное меню ОС (NativeMenu): вид и подсветку рисует ОС, пункты — программы. Вверху строка состояния «IP скрыт · NL · Нидерланды 01 · 42 мс» (не нажимается), дальше «Выключить защиту» (без защиты — «Включить защиту»), «Сменить сервер» — выбранный, избранные и недавние, до пяти, и «Все серверы…», «Обновить серверы», «Открыть окно», «Проверка» и «Закрыть интерфейс» с подсказкой «VPN и блок при обрыве продолжат работать» (без установленной службы — «Закрыть программу»). Значок — щит цвета состояния с белым знаком; подключение — синим. Сочетаний клавиш у пунктов нет. Выбранный сервер отмечает ОС: на Windows (меню рисует Avalonia) — точкой, на macOS — галочкой, в GNOME — точкой; серверы на всех ОС — списком внутри меню под подписью «Сменить сервер», без подменю вбок. Нажимается: значок открывает и закрывает меню, «Выключить защиту» гасит щит, «Сменить сервер» — списком прямо в меню (DECISIONS.md, п. 14), выбор сервера закрывает меню.

Установка службы — шаг первого запуска (доска 10): «Установить» запускает файл службы с правами, ОС спрашивает разрешение своим окном. Windows — запрос UAC (подписи кода пока нет, поэтому «Издатель: неизвестно»); macOS — пароль администратора через osascript (текст запроса — системный, программа свой не задает); Linux — pkexec, окно агента polkit оболочки. Служба после установки: Windows — служба Windows, блок при обрыве — WFP, установщик MSI; macOS — LaunchDaemon (launchd), блок — pf, образ .dmg; Linux — служба systemd, блок — nftables, пакеты .deb и .rpm. Пока ОС ждет ответа, окно — в состоянии «идет установка»: кнопка «Устанавливаем…» и «Без службы — только режим прокси» недоступны, у строки службы — «60% · Файлы скопированы · подготавливаем регистрацию». «Да / OK / Подтвердить» — служба установлена, «Нет / Отменить / Отмена» и щелчок мимо запроса — красная строка «Установка отменена: права администратора не даны», «Установить» спрашивает снова.
