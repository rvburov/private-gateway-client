Значок в трее и его меню (TrayViewModel программы) — системное меню ОС, здесь Windows 11. Щелчок по щиту в трее открывает меню: строка состояния (не кнопка), «Включить защиту» / «Выключить защиту», «Сменить сервер» — списком прямо в меню, без подменю вбок (DECISIONS.md, п. 14): выбранный, избранные и недавние, не больше пяти, и «Все серверы…», «Обновить серверы», «Открыть окно», «Проверка», «Закрыть». Значок — щит цвета состояния с белым знаком; при подключении — насыщенный синий индикатора, а не бледное кольцо. Пункт «Закрыть» зависит от службы: установленная работает и без окна — «Закрыть интерфейс» с подсказкой «VPN и блок при обрыве продолжат работать»; служба пользователя уходит вместе с окном — «Закрыть программу» с подсказкой «Прокси остановится вместе с программой»; в демо — «Закрыть программу» без подсказки. Меню рисует ОС: наведение и вид — как у Windows, не как кнопки окна; выбранный пункт закрывает меню, щелчок по щиту в трее открывает его снова. Снять блокировку из трея программа не дает молча: открывает окно с вопросом «Снять защиту?» (доска 18). macOS и Linux — доска 21. На macOS левый щелчок по щиту и щелчок по значку в Dock открывают окно. Правый щелчок по щиту открывает меню.

macOS: левое нажатие открывает окно, правое — меню. Значок остается в строке меню после импорта, переключения VPN/прокси и конфликта с другим VPN. Крестик прячет окно при включенном фоновом режиме; Cmd+Q и «Завершить» в Dock закрывают интерфейс полностью. Установленная служба продолжает работать.
