Основы дизайн-системы — то, из чего собран каждый экран: цвета, шрифты, отступы, скругления, тени, размеры раскладки и все 58 значков. Источник один — shared/specifications/design-tokens.json: из него при сборке получаются тема Avalonia (Tokens.axaml), Compose (Tokens.kt), SwiftUI (Tokens.swift) и assets/tokens.css этого макета. Каждая плашка закрашена самой переменной CSS, под ней — ключ токена и переменная; значения смотрите в tokens.css. Не экран программы, поэтому без рамки устройства.

Private Gateway · дизайн-система v1.1

Основы

Одни значения для всех версий: C# · Avalonia (Windows, macOS, Linux), Kotlin · Compose (Android), Swift · SwiftUI (iOS). Значения переносятся в ресурсы один в один: ключ в моноширинном шрифте — имя ресурса (color.accent.base → PgBrush.Accent.Base, PgColor.Accent.Base, --pg-color-accent-base).

Щит с галочкой (Icon.Shield + Icon.Mark.Ok) на сетке 24 × 24, линия 1,8, скругленные концы. Наименьший размер — 16 px, вокруг знака — свободное поле не меньше ¼ его высоты. Знак всегда синий (accent.base): зеленый, оранжевый, янтарный и красный — только у кнопки-щита и плитки состояния.
