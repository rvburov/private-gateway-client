Настройки (SettingsPage программы). «Основные» сохраняются сразу; форма внешнего прокси на десктопе применяет черновик кнопкой «Сохранить прокси». «Только прокси» — только после диалога «Перейти в режим прокси?», обратно — «Перейти в режим VPN?». В режиме прокси блок при обрыве недоступен, а щит островка после подтверждения — «Прокси». Выключить блок при обрыве — тоже через диалог. Подпись под уведомлениями меняется по выбору. Строки «Для опытных» открывают свои экраны: 5, 6, 13, 12, 7, 14, 15. Справа — тот же экран в режиме «Только прокси»: отдельная внешняя цель, не выбранный VPN-сервер. Протокол и авторизация меняют поля и пояснения; Кнопка сохранения проверяет только форму, не сетевое подключение. В макете учетные данные остаются в памяти страницы и не отправляются.

Режим
Весь трафик Windows идет через туннель: браузеры, терминал, Git, фоновые службы. Системный прокси можно отдельно включить в «Подключении и ядре». Весь трафик Windows идет через выбранный VPN-сервер. Дальнейший выход выбирает сервер; учетные данные настроенного на нем прокси здесь не нужны. Прокси не покрывает весь трафик: часть программ пойдет напрямую. Блок при обрыве недоступен. Прокси не охватывает весь трафик. WebRTC может раскрыть ваш IP. Блок при обрыве недоступен.

Перейти в режим VPN?

Активное подключение сменится на выбранный VPN-сервер. Настройки прокси сохранятся.

Перейти в режим прокси?

Через сервер пойдут только браузеры и программы, которые берут системный прокси. Остальной трафик — терминал, Git, фоновые службы — пойдет напрямую, блок при обрыве работать не будет. Если защита включена, подключение сразу перезапустится в режиме прокси.Блок при обрыве работать не будет. Текущее подключение сменится на внешний прокси, если он настроен. Настройки VPN сохранятся.

Выключить блок при обрыве?

Если VPN оборвется, трафик пойдет напрямую через провайдера — сайты увидят ваш реальный IP.
