Настройки (SettingsPage программы). «Основные» сохраняются сразу; форма внешнего прокси на десктопе применяет черновик кнопкой «Сохранить прокси». «Только прокси» — только после диалога «Перейти в режим прокси?», в режиме прокси блок при обрыве недоступен, а щит островка после подтверждения — «Прокси». Выключить блок при обрыве — тоже через диалог. Подпись под уведомлениями меняется по выбору. Строки «Для опытных» открывают свои экраны: 5, 6, 13, 12, 7, 14, 15. Справа — тот же экран в режиме «Только прокси»: отдельная внешняя цель, не выбранный VPN-сервер. Протокол и авторизация меняют поля и пояснения; Кнопка сохранения проверяет только форму, не сетевое подключение. В макете учетные данные остаются в памяти страницы и не отправляются.

Настройки
Основные
Режим
Весь трафик Windows идет через туннель: браузеры, терминал, Git, фоновые службы. Системный прокси можно отдельно включить в «Подключении и ядре». Весь трафик Windows идет через выбранный VPN-сервер. Дальнейший выход выбирает сервер; учетные данные настроенного на нем прокси здесь не нужны. Прокси не покрывает весь трафик: часть программ пойдет напрямую. Блок при обрыве недоступен. Устройство → внешний прокси → интернет, без VPN-сервера. Только приложения, использующие прокси. Блок при обрыве недоступен.
Внешний прокси Введите параметры внешнего прокси. Выбранный VPN-сервер сохранится отдельно.
Протокол прокси
Способ авторизации
Логин и пароль сохраняются в защищенном хранилище ОС и не включаются в отчет.
TCP через SOCKS5. UDP доступен только при поддержке UDP ASSOCIATE внешним прокси; успешный TCP этого не подтверждает. HTTP CONNECT и HTTPS-прокси передают TCP. UDP этим подключением не поддерживается. HTTP и SOCKS5 сами не шифруют участок до прокси, включая авторизацию. HTTPS сайта защищает его содержимое отдельно. HTTPS шифрует участок от устройства до прокси с проверкой сертификата. Дальнейшую защиту соединения с сайтом определяет HTTPS самого сайта. Режим не перехватывает весь трафик и DNS системы. Собственный DNS браузера и программы без прокси могут идти отдельно. Разрешенные исключения сайтов и локальной сети продолжают действовать.
Локальный HTTP/SOCKS-порт приложения и системный прокси настраиваются отдельно в «Подключение и ядро».
Блок при обрыве (Kill Switch) Нет туннеля — нет интернета. Защита от утечек при обрыве.

Уведомления Важные и обычные: подключение, серверы, обновления Обрыв, блокировка интернета, вход в Wi-Fi, сбой службы Только значок в трее меняет цвет. Окно и трей покажут все

Перейти в режим прокси?

Через сервер пойдут только браузеры и программы, которые берут системный прокси. Остальной трафик — терминал, Git, фоновые службы — пойдет напрямую, блок при обрыве работать не будет. Если защита включена, подключение сразу перезапустится в режиме прокси.После перехода блок при обрыве работать не будет. Прокси охватывает только использующие его приложения. Текущее подключение сменится на внешний прокси; если он еще не настроен, подключение завершится. VPN-сервер и его настройки сохранятся.

Выключить блок при обрыве?

Если VPN оборвется, трафик пойдет напрямую через провайдера — сайты увидят ваш реальный IP.
