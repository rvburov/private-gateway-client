Настройки (SettingsPage программы). «Основные» сохраняются сразу. «Только прокси» — только после диалога «Перейти в режим прокси?», в режиме прокси блок при обрыве недоступен, а щит островка после подтверждения — «Прокси». Выключить блок при обрыве — тоже через диалог. Подпись под уведомлениями меняется по выбору. Строки «Для опытных» открывают свои экраны: 5, 6, 13, 12, 7, 14, 15. Справа — тот же экран в режиме «Только прокси».

Основные
Режим
Весь трафик Windows идет через туннель: браузеры, терминал, Git, фоновые службы. Системный прокси можно отдельно включить в «Подключении и ядре». Прокси не покрывает весь трафик: часть программ пойдет напрямую. Блок при обрыве недоступен.
Блок при обрыве (Kill Switch) Нет туннеля — нет интернета. Защита от утечек при обрыве.

Подключаться при запуске Только к выбранному вами серверу
Сворачивать в трей Закрытие окна не отключает VPN
Уведомления Важные и обычные: подключение, серверы, обновления Обрыв, блокировка интернета, вход в Wi-Fi, сбой службы Только значок в трее меняет цвет. Окно и трей покажут все

Перейти в режим прокси?

Через сервер пойдут только браузеры и программы, которые берут системный прокси. Остальной трафик — терминал, Git, фоновые службы — пойдет напрямую, блок при обрыве работать не будет. Если защита включена, подключение сразу перезапустится в режиме прокси.

Выключить блок при обрыве?

Если VPN оборвется, трафик пойдет напрямую через провайдера — сайты увидят ваш реальный IP.
