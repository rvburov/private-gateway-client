# Журнал решений агента

Решения, которые агент принял сам, без согласования, — по поручению пользователя «действуй
самостоятельно, спорное выбирай лучшим вариантом и фиксируй». Каждое можно пересмотреть: номер,
дата, что выбрано, какие были варианты, почему так. Решения, согласованные с пользователем, — в
[DECISIONS.md](DECISIONS.md).

Как пересмотреть: назвать номер — агент объяснит подробнее или переделает.
