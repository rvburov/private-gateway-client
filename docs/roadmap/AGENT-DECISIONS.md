# Журнал решений агента

Решения, которые агент принял сам, без согласования, — по поручению пользователя «действуй
самостоятельно, спорное выбирай лучшим вариантом и фиксируй» и «вопросы не задавать, а делать и
записывать, что требовалось выбрать; обсудим после готового кода». Сюда попадают и продуктовые
развилки. Каждое можно пересмотреть: номер, дата, что выбрано, какие были варианты, почему так.
Решения, согласованные с пользователем, — в [DECISIONS.md](DECISIONS.md).
