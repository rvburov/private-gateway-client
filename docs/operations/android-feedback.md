# Исправления обратной связи Android — 2026-11-23

В списках всех платформ остаются актуальный пинг и подписи «тайм-аут», «выбран», «активен».
Устаревший или неподтвержденный результат — «—». TLS, DNS и причины отказов остаются
в карточке сервера. Тайм-аут не подменяет другие ошибки. Проверки защиты не меняются.

Загрузчик Android делает не более трех попыток при обрыве или коротком ответе,
использует Range для частичного файла и безопасно перезаписывает его при ответе 200.
Ответ 206 принимается только с точным Content-Range. Перед установкой проверяются размер
и SHA-256 из подписанного манифеста; непроверенный файл после отказа удаляется.
Тайм-аут чтения отдельного блока — 60 секунд. Прогресс обновляется каждые 256 КБ.
Это исправление нового клиента; уже установленная 0.3.1 сама его не получает.

Страна числового адреса определяется локально. Для имен хостов фоновая проверка флагов
использует DNS текущей сети ОС с ограничением ожидания, без привязки к физическому
интерфейсу и без обхода VPN. Неизвестная страна повторно проверяется при следующем запуске.
При неоднозначной стране или недоступном DNS сохраняется исходный флаг ссылки либо глобус.

Отчеты пользователя относятся к 0.4.0 и не содержат самой остановки загрузки 0.3.1.
Обрывы и отсутствие Range воспроизводятся локальным HTTP-сервером в тестах. Физическое
устройство пользователя и его подписки в облаке не проверялись.

Локальная проверка: Android core 1177/1177, приложение 413/413, lint без ошибок;
десктоп UI 555/555, Unit 1549 успешно и 6 пропусков по условиям среды, сборка без
предупреждений. При удалении повторов три теста загрузчика обнаруживают регрессию;
после восстановления все 15 тестов загрузчика проходят. iOS и другие ОС проверяются в CI.
