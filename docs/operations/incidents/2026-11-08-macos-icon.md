# macOS: полосы вместо маленькой иконки

Дата: 2026-11-08. Обнаружено в m4.10 и более ранних сборках.

Finder, список «Программы» и маленькая иконка в запросе Связки ключей показывали цветные полосы.
Dock и трей показывали правильный щит. Файл ICNS установленного приложения совпал с файлом репозитория.
`iconutil -c iconset` воспроизвел искажение кадров 16 и 32 px, при этом 128 px был правильным.
Ошибка в упаковке иконки; повторная установка того же DMG ее не устраняла.

## Исправление

Удален ручной код контейнера ICNS. `gen-icons.cs` на любой ОС рисует десять PNG из прежних геометрий и токенов.
На Mac `package-macos.sh` собирает ICNS через `iconutil`, затем проверяет прозрачность и непрозрачные цвета всех кадров системным декодером
до подписи приложения. Windows ICO и Linux SVG сохраняются. Сам образ приложения пользователю не изменяется на месте.

Основание: [Apple, High Resolution Guidelines: iconset и iconutil](https://developer.apple.com/library/archive/documentation/GraphicsAnimation/Conceptual/HighResolutionOSX/Optimizing/Optimizing.html).
Код из сторонних проектов не переносился.

## Проверки

- `bash scripts/tests/macos-icon-smoke.sh`: нативная сборка, декодирование и сравнение 10 кадров с исходными PNG: вся маска alpha и RGB непрозрачных пикселей.
  Цвет полупрозрачного края не сравнивается: iconutil перекодирует маленькие кадры через RGB и отдельную маску.
- Аргумент скрипта — готовый ICNS: проверяется именно ресурс приложения внутри DMG.
- Отрицательная проверка выполнена: прежний ICNS завершил тот же тест с ошибкой на кадрах 16 и 32 px;
  исправленный набор прошел 10/10. Маска и непрозрачные цвета совпали без отклонения.
- CI запускает проверку на macOS ARM и Intel; локальный прогон — только ARM. Сеть и служба для этой проверки не нужны.
- Unit, UI и Architecture выполняются локально. Network выполняется в CI: локальные Xray/sing-box могут вызвать
  PGC-NET-010 в работающем приложении пользователя, даже если тесты используют только loopback.

Локально на M4: Unit/UI/Architecture — 1655 всего, 1654 успешно, 0 ошибок, 1 пропуск по условиям ОС/прав.
Первый прогон UI обнаружил отсутствие инициализированного рендера Avalonia в обычном Fact; чтение PNG переведено
на SkiaSharp, повторный полный UI-прогон — 454/454. Нативная проверка — 10/10, старый ICNS отвергнут.

## Проверка пользователем

Завершить приложение через Cmd+Q, заменить его в «Программах» версией m4.11 из DMG, запустить из «Программ».
Убедиться, что в Finder в режимах списка и значков, в пути папки и Dock виден щит. В следующем штатном запросе
Связки ключей проверить маленькую иконку приложения; сам замок задает macOS. Специально вызывать запрос или менять
разрешения Связки ключей не требуется. Трей по-прежнему показывает состояние защиты.

Для этой правки удаление или обновление службы не требуется, если она уже m4.10. Если macOS сохраняет старое
изображение после замены, сначала закрыть и открыть окно Finder; затем проверить после обычной перезагрузки.
Кеши ОС и настройки сети автоматически не удаляются. Реальные системные окна после установки проверяет пользователь.
