# Изменения / Changelog

Что изменилось от выпуска к выпуску — для людей, коротко. Заметки каждого выпуска на GitHub собираются из коммитов
(«Новое», «Исправлено»); здесь — то же по выпускам целиком. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [Не выпущено] — 0.1.0, первая версия

### Новое — Windows, macOS, Linux

- Серверы: VLESS (с REALITY), VMess, Trojan, Shadowsocks, WireGuard, Hysteria2 и TUIC (через sing-box за Xray); подписки (base64, Clash/Mihomo YAML,
  sing-box JSON) с обновлением по расписанию, по умолчанию только через VPN; QR — с картинки и «Поделиться»; ручной
  выбор сервера, избранное, поиск, задержка через сам сервер.
- Два режима: прокси (вход ядра на 127.0.0.1 и системный прокси) и VPN (TUN — весь трафик машины через сервер).
- Защита: блок при обрыве (Windows — WFP, Linux — nftables, macOS — pf), на Linux — и для пересланного трафика
  виртуальных машин и контейнеров; DNS только через туннель, IPv6 через сервер или закрыт, FakeDNS; «Строгий режим», «Защита при загрузке» —
  блок до входа пользователя; пауза для входа в Wi-Fi отеля или кафе на 5 минут.
- Надежность: переподключение только к выбранному серверу, смена сети, сон и пробуждение, восстановление после аварии
  службы; «Работает другой VPN»; уведомления ОС; журнал на диске без секретов.
- «Проверка»: проверки утечек (внешний IP, DNS, IPv6, WebRTC), до и после VPN, сетевой инспектор (адаптеры, маршруты,
  DNS, соединения и процессы, замеры DNS, TCP, TLS, пинг и трассировка), обезличенный отчет для поддержки.
- Network Lab: путь до сайта по участкам, уровни OSI на данных машины, события сети с объяснениями, сценарии
  «сайт не открывается» и «как меняется путь при VPN».
- Раздельный режим: программы и сайты мимо туннеля.
- Выпуск: MSI для Windows, `.deb` и `.rpm` для Linux, образ диска для macOS, архивы; SBOM и `SHA256SUMS`;
  THIRD-PARTY-NOTICES; обновления — подписанный манифест, поэтапная раскатка, атомарная установка и откат на прежнюю
  версию; служба ставится и удаляется вместе с программой и убирает за собой сетевые правила.
- Интерфейс по макету: светлая и темная темы из токенов, русский и английский, доступность, трей, автозапуск.

### Новое — Android

- Подписки, QR (камерой и с картинки), серверы, ручной выбор, DNS, уведомления, фоновое обновление подписок.
- VpnService с ядром Xray (libXray); «Постоянная VPN» и «Блокировать соединения без VPN» — где их дает Android, с
  флагами в «Настройках» и «Интернет закрыт Android».
- Инспектор сети на «Проверке»: сети телефона, внешний IP и провайдер, замеры DNS, TCP и TLS.
- «Лицензии открытых компонентов» — список сверяется с зависимостями при каждой сборке.

### Безопасность

- Ключи серверов и адреса подписок — только в хранилище ОС; служба не принимает от окна готовый конфиг ядра, пути и
  команды — только описание сервера и настройки по контракту IPC; вход ядра для TUN — с паролем на одно подключение.
- Сеть процесса окна запрещена анализатором (кроме загрузки подписок): все остальное делает служба.
- Подробно — [PRIVACY.md](PRIVACY.md), [SECURITY.md](SECURITY.md), [docs/security/threat-model.md](docs/security/threat-model.md).

### Известные ограничения

- Программа не подписана сертификатом разработчика (Windows SmartScreen и macOS Gatekeeper предупредят при первом
  запуске; как поставить — в заметках выпуска). Подпись — в разделе ROADMAP «Отложено».
- Windows: пересланный трафик WSL, Hyper-V и контейнеров за WinNAT блок при обрыве проверяется у пользователя (пункты
  этапа 3 ROADMAP).
- Android: к Hysteria2 и TUIC подключиться нельзя — ссылки разбираются и хранятся, но libXray таких протоколов не
  знает (на десктопе их ведет sing-box).
- iOS — в работе (этап 10 ROADMAP).
- На Android нет пинга, трассировки, списка соединений и процессов — их не дает приложению сам Android.
